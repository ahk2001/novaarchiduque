## Estructura del Proyecto

- `index.html`: Landing page editorial en HTML5 semántico, CSS moderno y Vanilla JS, con popup modal de triaje inteligente paso a paso hacia WhatsApp (`+34 658 16 94 23`).
- `assets/`: Logotipo oficial, favicon, imágenes de cabecera y recursos gráficos de formación (Permiso B, CAP, Tráiler, Carretillero, Tacógrafo y Gestoría DGT).

- `robots.txt` y `sitemap.xml`: Configuración SEO para indexación en buscadores.
- `docs/`: Documentación estratégica y datos de referencia internos (excluidos de indexación en `robots.txt`).
- `video/`: Recursos gráficos complementarios para presentaciones (excluidos de indexación en `robots.txt`).
